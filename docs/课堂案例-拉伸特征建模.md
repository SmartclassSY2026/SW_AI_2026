# 智慧教学课堂案例

## 计算机辅助设计（SolidWorks）—— 拉伸特征建模

> **数字化重构传统课堂的具体案例**
> 聚焦专业核心理论课程，以问题导向、知识重点难点梳理、分层探究构建智慧教学模式，融合智能辅助教学工具与多模态知识呈现，建立可量化、可追踪的科学评价体系。

---

## 一、课程基本信息

| 项目 | 内容 |
|------|------|
| 课程名称 | 计算机辅助设计（SolidWorks） |
| 课题 | 拉伸特征建模——从二维草图到三维实体 |
| 学时 | 2学时（90分钟） |
| 教学对象 | 机械类专业本科生（1个教学班，约40人） |
| 教学环境 | 机房（每人1台电脑，已装SolidWorks）+ AI教学助手网页 |
| 工具平台 | 计算机辅助设计AI教学助手（腾讯元器智能体 + 飞书多维表格 + GitHub Pages） |

---

## 二、教学目标

### 知识目标
- 理解拉伸特征的建模原理（草图 → 特征 → 三维实体）
- 掌握拉伸特征的创建流程：绘制草图 → 启动拉伸 → 选择轮廓 → 设置终止条件 → 完成
- 区分不同终止条件类型（给定深度、成形到下一面、两侧对称等）

### 能力目标
- 能独立完成简单零件的三维建模
- 能正确处理草图封闭性、多轮廓选择等操作难点
- 养成"先分析建模思路，再动手操作"的工程思维

### 思政目标
- 培养精益求精的工匠精神——每个参数都关乎产品质量
- 树立严谨求实的工程态度——尺寸精度是工程语言
- 增强责任意识——设计决定制造，制造关乎安全

---

## 三、教学重点与难点

| 类别 | 内容 | 说明 |
|------|------|------|
| **重点** | 拉伸特征创建流程 | 草图绘制 → 启动拉伸 → 终止条件设置 → 完成特征 |
| **重点** | 草图必须为封闭轮廓 | 不封闭的草图无法生成实体，是学生最常犯的错误 |
| **难点** | 几何约束的添加 | 水平、竖直、相切等约束影响草图的可修改性 |
| **难点** | 多轮廓拉伸 | 一个草图中含多个封闭区域时的选择逻辑 |
| **难点** | 薄壁拉伸与拔模 | 进阶参数设置，容易混淆方向和厚度 |

## 四、课堂场景完整描述

### 【第一阶段】课前：预习与学情诊断

> **对应比赛要求：问题导向、可追踪评价、智能辅助教学工具应用**

#### 课前2天

教师在课程群发布AI教学助手网址，要求学生提前登录预习。

**学生端操作：**
1. 打开网页，输入姓名和学号登录
2. 系统自动加载该学生最近5条历史问答记录（若之前用过）
3. 页面显示AI助教，学生可直接提问预习中遇到的疑问

**AI助教交互示例：**
> 学生问：拉伸特征是什么意思？
> AI答：拉伸特征是将二维草图沿垂直方向延伸为三维实体的建模方法。操作步骤：1. 在基准面上绘制封闭草图轮廓；2. 点击【特征】→【拉伸凸台/基体】；3. 在属性窗口设置拉伸方向和终止条件；4. 输入深度值，点击确认。
> **易错点提醒**：草图必须是封闭轮廓，否则无法生成实体。常见错误是草图有开口或重叠。
> **思政小课堂**：拉伸建模中每一毫米的深度都决定零件的最终形态，工程设计容不得半点马虎，这就是工匠精神的体现。

#### 课前1天——教师查看学情

**教师端操作：**
1. 点击登录页"教师入口"，输入密码进入教师后台
2. 查看飞书多维表格汇总的全班预习记录
3. 从记录中发现：
   - 60%学生问了"草图封闭性"相关问题 → 这是重点，课堂要强调
   - 30%学生问了"终止条件"相关 → 难点，需要详细演示
   - 10%学生问了拔模角度 → 少数，可作为挑战任务

> **数字化重构体现**：传统课堂教师只能凭经验预判难点；本案例中，教师课前就能从AI助教的真实提问数据中**精准诊断学情**，实现"以学定教"。

---

### 【第二阶段】课中：核心教学（90分钟）

#### 环节1：情境导入——问题导向（5分钟）

> **对应比赛要求：问题导向、多模态知识呈现**

教师屏幕展示一个真实的机械零件实物照片（如法兰盘），提问：

> "同学们看这个法兰盘，它中间有孔、四周有螺栓孔、整体是一个圆盘形。如果让你在SolidWorks里把它建出来，你会怎么做？"

引导学生思考：这个零件不是一步画出来的，而是"先画草图轮廓，再拉伸出厚度，最后切除孔"。

**点题**：今天我们学习SolidWorks中最核心的特征建模方法——**拉伸特征**。它是将二维想法变成三维实体的桥梁。

> **数字化重构体现**：从真实工程零件出发（图片呈现），而非直接打开软件讲菜单命令。问题导向激发学生主动思考建模思路。

---

#### 环节2：重点讲解——知识梳理（15分钟）

> **对应比赛要求：知识重点难点梳理、多模态知识呈现（文字+演示）**

教师讲解拉伸特征的核心知识，配合屏幕操作演示：

**1. 拉伸特征三要素**
- 草图轮廓（必须封闭）
- 拉伸方向（默认垂直草图平面）
- 终止条件（给定深度 / 成形到下一面 / 两侧对称 / 完全贯穿）

**2. 操作流程演示**（教师实时操作SolidWorks）
```
选择基准面 → 进入草图绘制 → 绘制封闭轮廓 → 退出草图
→ 特征工具栏点击"拉伸凸台/基体" → 设置终止条件和深度 → 确认完成
```

**3. 重点强调**（板书/PPT标记）
- 🔴 **难点**：草图必须封闭——开口草图无法拉伸，这是操作失败的第一大原因
- 🔴 **难点**：几何约束——添加水平/竖直/相切约束，保证草图可修改
- 🟡 **重点**：多轮廓——一个草图可含多个封闭区域，拉伸时可全选或选部分

> **数字化重构体现**：传统课堂靠教师口头强调重点；本案例中重点难点来源于课前AI助教收集的真实学情数据，"哪些问题学生问得多，哪些就是课堂重点"，实现知识重点难点的**数据驱动梳理**。

---

#### 环节3：分层探究——学生操作+AI辅助（40分钟）

> **对应比赛要求：分层探究、智能辅助教学工具应用、问题导向、可追踪**

教师布置三个层次的探究任务，学生根据自身水平选择：

| 层次 | 任务 | 目标 | 适用学生 |
|------|------|------|----------|
| **基础** | 绘制矩形草图，拉伸成长方体（50×30×20mm） | 掌握拉伸基本流程 | 预习未提问或基础薄弱 |
| **进阶** | 绘制法兰盘草图（外圆+内圆），拉伸后切除螺栓孔 | 掌握多轮廓拉伸+切除特征 | 预习有提问的中等生 |
| **挑战** | 绘制支架草图，使用薄壁拉伸+拔模角度 | 掌握薄壁和拔模参数 | 预习问了拔模的拔尖生 |

**学生操作流程：**
1. 学生打开SolidWorks开始建模
2. 遇到操作困难时，**随时打开AI教学助手网页提问**，无需举手等教师
3. AI立即返回：操作步骤 + 易错点提醒 + 思政小课堂

**AI助教交互示例（进阶任务场景）：**
> 学生问：法兰盘的螺栓孔怎么打？
> AI答：使用拉伸切除特征。操作步骤：1. 选择法兰盘上表面作为草图基准面；2. 绘制螺栓孔的草图圆（注意用圆周阵列均布6个孔）；3. 退出草图后点击【特征】→【拉伸切除】；4. 终止条件选"完全贯穿"，确认完成。
> **易错点提醒**：螺栓孔建议用"圆周阵列"功能均布，而非逐个绘制，这样修改孔数时只需改一个参数。阵列前需先过圆心画一条中心线作为阵列轴。
> **思政小课堂**：螺栓孔的均布精度直接影响法兰密封性能，一颗螺栓的偏差可能导致泄漏事故。工程无小事，细节定成败。

**教师角色：**
- 巡场观察学生操作进度
- 重点辅导进度最慢的学生（基础层）
- 通过教师后台实时查看全班提问记录，发现共性问题准备集中讲解

> **数字化重构体现**：
> - 传统课堂：40个学生同时操作，教师只有1人，举手等待是常态，问题积压到课后
> - 本案例：AI助教**一对一即时答疑**，学生不等不堵；分层任务让不同水平学生各有目标；教师从"答疑机器"解放出来，聚焦在真正需要辅导的学生身上
> - 所有提问自动记录到飞书，**可追踪、可回溯**

---

#### 环节4：成果展示与点评（15分钟）

> **对应比赛要求：可量化评价、多模态呈现**

1. 教师选3名学生（基础/进阶/挑战各1人）在大屏幕展示建模成果
2. 结合教师后台的提问记录点评：
   - "基础层的同学问了草图封闭问题，说明他卡在了第一步，后来通过AI辅导解决了"
   - "挑战层的同学主动问了薄壁拉伸方向，说明他在深度思考"
3. 展示优秀作品，引导学生互相学习

> **数字化重构体现**：传统点评靠教师记忆和主观印象；本案例点评基于**飞书记录的真实提问轨迹**，"谁问了什么、怎么解决的"一目了然，评价有据可依。

---

#### 环节5：课堂小结（15分钟）

教师总结本节课重点：

> 1. 拉伸特征 = 封闭草图 + 拉伸方向 + 终止条件
> 2. 草图必须封闭——这是第一大易错点（课前数据已验证）
> 3. 多轮廓拉伸——进阶技巧，灵活高效
> 4. 工程启示：从二维到三维，每一毫米都承载工程责任

**布置课后任务**：
- 基础巩固：完成教材上的拉伸练习题3道
- 拓展探究：思考"旋转特征"与"拉伸特征"的区别，下次课预习

---

### 【第三阶段】课后：巩固与评价追踪

> **对应比赛要求：可量化、可追踪的科学评价体系**

#### 课后持续使用

1. 学生课后继续使用AI教学助手复习和提问
2. 所有问答持续记录到飞书多维表格

#### 教师评价数据

教师后台可查看本节课的完整数据：

| 评价指标 | 数据来源 | 量化方式 |
|----------|----------|----------|
| 课前参与率 | 飞书记录 | 登录提问人数 / 全班人数 |
| 课中互动频次 | 飞书记录 | 课中提问总条数、人均条数 |
| 知识点覆盖 | AI回答关键词 | 草图封闭/终止条件/多轮廓/拔模各占比 |
| 难点掌握 | 提问分布 | 各难点相关提问数量变化 |
| 学习持续性 | 课后记录 | 课后继续提问人数、时间分布 |
| 个体追踪 | 单学号记录 | 每个学生完整提问轨迹 |

> **数字化重构体现**：传统课堂评价靠期末考试一次性判定；本案例构建了**全过程、可量化、可追踪的评价体系**——从课前预习到课中互动到课后巩固，每个环节都有数据记录，每个学生都有个性化学习轨迹，实现科学的过程性评价。

## 七、教学反思与特色总结

### 传统课堂 vs 数字化重构课堂对比

| 维度 | 传统课堂 | 数字化重构课堂 |
|------|----------|----------------|
| 答疑方式 | 举手等教师，1对40 | AI即时一对一，0等待 |
| 难点确定 | 教师凭经验预判 | 课前数据精准诊断 |
| 任务分层 | 统一进度统一任务 | 三层任务自主选择 |
| 评价方式 | 期末一次性考试 | 全过程数据追踪 |
| 思政融入 | 单独章节或口头 | AI回答自然融入每个知识点 |
| 课后追踪 | 基本无 | 持续记录、可回溯 |

### 核心特色

1. **数据驱动的精准教学** — 重点难点不靠猜，来自学生真实提问数据
2. **AI赋能的个性化辅导** — 每个学生有自己的AI助教，因材施教
3. **全过程可量化评价** — 课前/课中/课后每个环节都有数据支撑
4. **思政自然融入** — 不说教、不生硬，结合操作知识点自然渗透
5. **零成本可持续** — 全部基于免费平台，可长期运行、可复制推广
